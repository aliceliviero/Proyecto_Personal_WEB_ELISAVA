# Project Memory — Echoes in the City: a spatial and emotional cartography of music

## Objective
*Echoes in the City* is an interactive web platform created with HTML, CSS, and JavaScript. Its objective is to connect Spotify listening history, Google Maps geolocation coordinates, and emotional states in a collective sound cartography, transforming isolated urban listening into a shared experience of spatial memory and belonging.

## Current Structure
- `index.html`: main page structure, project overview, and interactive research question toggle.
- `style.css`: visual styles implementing the Dark Mode identity (`#0F1115` background, `#F3F4F6` text, `#BD2DAA` titles, `#F57CE5` subtitles, `#B9FAF8` accents) and Helvetica typography.
- `script.js`: interactive behavior for the button that reveals or hides the research question.

## Current Decisions
- Maintain a lightweight structure using vanilla HTML, CSS, and JavaScript without external frameworks.
- Separate structure, visual styling, and interactive logic into distinct files.
- Use a high-contrast Dark Mode palette and Helvetica typography (`Bold`, `-0.019em` tracking) to evoke urban nightscapes and sonic data visualization.
- Reveal the research question interactively via a toggle button on the landing page.

## Pending Tasks
- Refine the visual identity: choose a secondary typeface to pair with Helvetica, design the project logotype, and define a cohesive visual integration between the map, editorial texts, and UI components.
- Implement the interactive map exploration and user contribution flow for songs and spatial memories.
- Address key design questions:

  2. What is the most intuitive interaction design model for enabling users to contribute their own songs and memories to specific city coordinates?
